# KadaBook Premium Presentation Website

A presenter-controlled, animated React website built using the supplied KadaBook redesign ZIP.

## Run locally
1. Install Node.js 18+.
2. Extract this project ZIP.
3. Open a terminal in the project folder.
4. Run `npm install`
5. Run `npm run dev`
6. Open the local URL printed by Vite.

## Build for hosting
- `npm run build`
- Upload the generated `dist/` folder to Firebase Hosting, Vercel, Netlify or another static host.

## Presentation controls
- Click chapter names in the left navigation.
- Use the bottom-right arrows or keyboard ← / →.
- Scroll normally between chapters.
- On mobile, open the menu button to navigate.

## Important customisation before presenting
- In `src/main.jsx`, search for `Add your WhatsApp number · email · website here` and replace it with the official business contact details.
- Replace the illustrative expense sample with an approved real demo if desired.
- Pricing and plan feature allocation reflect the supplied project design reference: Credit Book LKR 750, Shop LKR 1,500, Pro LKR 2,500 monthly.
- The first-100 offer is presented as free installation/setup assistance and a 30-day trial with no obligation to subscribe.
- Daily follow-up is described as a team-led customer success process, not as an automated analytics capability.
- Three.js hero animation and Framer Motion transitions require a modern browser and WebGL. If WebGL is unavailable, the rest of the presentation remains usable.
