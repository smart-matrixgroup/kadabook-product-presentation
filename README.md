# KadaBook – Interactive Product Presentation

An immersive, interactive product presentation website for **KadaBook**, a smart business management application designed for small retail shops, grocery stores and kitchen businesses.

Built to help demonstrate KadaBook's features, benefits, subscription plans and business value through a modern, animated presentation experience.

## ✨ Overview

KadaBook helps small business owners manage their daily shop operations in one place.

This presentation website provides an interactive way to introduce the product to potential customers, demonstrate its features and explain how it can simplify everyday business management.

## 🚀 Key Features

- Interactive, slide-based presentation.
- Animated 3D elements powered by Three.js.
- Smooth transitions and animations.
- Responsive design for desktop, tablet and mobile.
- Product screenshots and application previews.
- Interactive chapter navigation.
- Keyboard navigation using arrow keys.
- Mobile-friendly navigation.
- Dedicated sections for features, pricing and launch offers.
- Presenter notes in Tamil.

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/smart-matrixgroup/kadabook-product-presentation.git
```

### 2. Navigate to the project

```bash
cd kadabook-product-presentation
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start development server

```bash
npm run dev
```

Open the local URL displayed in your terminal.

### 5. Build for production

```bash
npm run build
```

The production-ready files will be generated inside the `dist/` directory.
